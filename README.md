# SPA Lab — React

Учебное одностраничное приложение для СРС №1 (неделя 3). Проект демонстрирует компонентную структуру, `props`, состояние React, маршрутизацию, запрос к открытому API и фильтрацию.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Для production-сборки выполните `npm run build`, затем `npm run preview`.

## Функциональность

- Главная и «О проекте» переключаются через React Router (`HashRouter`), без перезагрузки документа.
- `Header` получает название приложения через `props`; `Main` получает заголовок, подпись, описание и содержимое.
- `Counter` использует `useState` для интерактивного счётчика.
- `PostsSection` загружает до 12 публикаций из JSONPlaceholder в `useEffect`, показывает состояния загрузки и ошибки, а поле поиска фильтрует заголовки и текст.
- Адаптивная вёрстка подходит для мобильных экранов. `HashRouter` позволяет размещать приложение на статическом хостинге GitHub Pages.

## Структура

```text
src/
  components/  # Header, Main, Footer, Counter, PostsSection
  views/       # HomeView и AboutView
  App.jsx      # маршруты и общий каркас
  main.jsx     # точка входа
  styles.css   # адаптивные стили
```
